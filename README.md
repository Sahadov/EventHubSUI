**Твой гид по событиям города**

Найди концерты, выставки, мастер-классы, спортивные матчи и любые другие мероприятия рядом с тобой.

## ✨ Возможности

* 📅 **Поиск событий** — по дате, категории или ключевым словам
* 📍 **Карта** — сразу видно, где проходит мероприятие
* ⭐ **Закладки** — сохраняй понравившееся
* 📝 **Подробности** — организаторы и место проведения
* ⚡ **Персонализация** — только то, что интересно именно тебе

EventHub помогает держать руку на пульсе города 🚀
